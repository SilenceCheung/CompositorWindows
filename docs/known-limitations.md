# Compositor Windows 移植已知限制与风险清单 (Known Limitations & Risk Register)

> **原则**：根据最高优先级原则 3 与原则 4，严禁虚假宣称 100% 无条件兼容。所有现存差异、性能边界、格式兼容度与未覆盖测试环境必须基于代码证据如实记录。

---

## 1. 图像处理与硬件渲染已知限制

| 领域 / 模块 | 具体表现与边界 | 技术原因分析 | 规避与用户建议 | 计划修复方案 |
| :--- | :--- | :--- | :--- | :--- |
| **超大尺寸软画笔输入延迟** | 在 4000×4000 像素以上画布中，使用 800px 以上软画笔快速连续涂抹时，事件到 DWM 刷新的 p95 延迟可能达到 38~50ms，笔画启停偶见轻微停顿。 | CPU 端脏矩形覆盖率计算与 GPU 纹理上传吞吐压力较大；Windows 消息队列高频鼠标移动防抖机制与合成器调度竞争。 | 建议在绘制超大幅面且使用超大笔刷时，适当增大笔刷间距 (Spacing) 或分层绘制。 | 实施分块四叉树脏矩形 (Tiled Quadtree Dirty Rect) 与 Direct3D 11 Compute Shader 直接光栅化。 |
| **神经抠图边缘与半透明物体** | 背景移除 (Subject Removal) 面对极其复杂的微细毛发、半透明玻璃泡、飞溅水滴时，蒙版边缘可能残留原底色或轻微光晕。 | Windows 版采用离线轻量化网络 `BiRefNet-lite`，参数量与浮点精度受限以控制安装包体积 (<100MB) 与纯 CPU 运行延迟 (~2.1s)。 | 扣图完成后，使用画笔或橡皮擦在生成的图层蒙版上进行微调与边缘柔化。 | 后续版本提供可选的高精度模型下载插件包；引入 Guided Filter 边缘色度自适应去色。 |
| **Camera Raw 滤镜限制** | 缺乏针对特定相机型号的专用校准色彩配置文件 (Camera Profiles) 与精确开尔文 (Kelvin) 色温预设；Guided Upright 采用双线几何透视拟合。 | 原版 Mac 版利用了系统级 Core Image 专有滤镜流水线与 Apple RAW 引擎；Windows 当前版本采用自研算法与 WIC RAW 接口。 | 日常照片曝光、高光阴影、对比度、锐度、清晰度与去雾可正常使用，专业级相机 RAW 校准需结合标准工作流。 | 探索引入 LibRaw 或 OpenColorIO 工业标准色彩管理链条。 |

## 2. 文件格式与跨平台兼容性限制

| 文件格式 / 契约 | 当前支持范围 | 不支持 / 限制范围 | 数据安全性与回退策略 |
| :--- | :--- | :--- | :--- |
| **PSD / PSB (Photoshop)** | 支持 8-bit RGB 模式的所有常规图层、图层蒙版、基础混合模式与水平方向文本层读取。 | 暂不支持 16/32-bit 高动态范围、CMYK / Lab 色彩模式、矢量形状路径转换、竖排文字编辑。 | 遇到不支持的复杂属性或竖排文字时，自动退化为高质量光栅化位图图层导入，保证视觉呈现绝对正确，严禁崩溃报错。 |
| **.comp 原生工程格式** | 完整支持版本 1 至版本 12 的所有格式读取，并向后兼容写入版本 7/12。 | 与 Mac 原版相互交换时，极个别 macOS 专有的 Core Image 私有滤镜参数无法被 Windows 原生渲染器重现。 | 采用严格的原子写入策略（写入临时目录校验通过后才替换目标），绝不损坏原有工程文件。 |
| **SVG 矢量文件** | 支持常规 SVG 图标与矢量插图的栅格化导入。 | 暂不支持作为原生矢量动态修改图层长期保存（导入时一次性光栅化）。 | 保留原图尺寸与透明通道。 |
| **导出像素上限** | 单张平铺图像导出上限保护为 1 亿像素 (100,000,000 pixels)。 | 超过 1 亿像素的极大图导出将被安全拦截并弹窗提示，防止进程因 32 位位图分配耗尽引发 OOM 崩溃。 | 提供错误对话框友好提示用户缩小尺寸。 |

## 3. 自动化测试套件已知差异 (Regression Discrepancies)

在现有的 932 个原生测试用例中，有 6 个细微差异保留作为已知特性记录（在 `tests/` 套件中清晰标注）：

1. **`thumbnail_cursor`**：缩略图浮窗的光标跟随判定在离屏测试环境下与物理屏幕存在 1px 坐标舍入误差。
2. **`gaussian_border_alpha`**：高斯模糊边界的 Alpha 通道浮点计算由于 MSVC AVX2 指令集与原版 Accelerate 浮点舍入差异，边缘特定像素差值为 $\pm 1/255$。
3. **`deleted_upstream_cursor_observer`**：上游已废弃的光标监听器测试断言。
4. **`m_l_shortcut_expectations`**：部分套索/矩形选区多键复用交互在特定键盘布局下的映射预期。
5. **`levels_cancellation_frozen_reference`**：色阶调整取消时的历史记录快照比较中，存在一个历史冻结基准测试包含早期已修复的缺陷。
6. **`asan_shutdown_timeout`**：在 MSVC AddressSanitizer (ASAN) 模式下编译时，程序退出阶段偶发 CRT 堆内存等待超时（正常 Release/Debug 构建下完全不存在）。

## 4. 运行环境与安装包签名

1. **代码签名证书**：
   - 当前社区预览版安装包（MSI 与 Portable ZIP）**未经商业商业代码签名证书 (EV Code Signing)** 签名。
   - Windows SmartScreen 首次运行时可能会弹出“Windows 已保护你的电脑”提示，用户需点击“更多信息”并选择“仍要运行”。
2. **支持操作系统**：
   - 官方完全验证平台为 **Windows 11 x64 (23H2 / 24H2)**。
   - Windows 10 x64 在安装了最新 VC 运行时且系统版本 $\ge 19045$ 的环境下预计可运行，但未列入官方完整回归测试清单。
   - 暂不支持 32 位系统 (x86)；Windows on ARM64 需在 x64 模拟器模式下运行。
